# 13 抖音本地生活数据渠道复核（2026-10-19）

起因：用户看到聚推客 2025-06-03 公告，抖音团购功能 2025-06-10 下线。research/12 §3.1 的聚推客方案作废。本文件取代 12 中关于团购结构化数据的结论。

## 1. 结论

截至 2026-10-19：

- **免费 API：没有。** 个人能用、返回抖音团购结构化数据（套餐名、现价、原价、销量、poi_id）的 API 一个都没找到。退路美团也不行：个人拿不到美团联盟 API，第三方的美团团购接口 2024-07 已停。
- **付费会员导出：有。** 灰豚、蝉妈妈、抖查查卖个人会员，网页里有团购门店和团购商品数据（套餐名、现价、原价、累计销量、门店），付费档可以导出。没有 API，只能手工导出；销量是第三方采集或估算；导出文件里有没有 poi_id、深圳覆盖多少，要登录才能验证。
- **免费文本：** 千帆搜索返回的抖音图文笔记正文、shipin 页口播转写。

## 3. 实测：可用的抖音侧文本

**千帆搜索（百度，`search_source=baidu_search_v2`，`search_filter.match.site=["www.douyin.com"]`）：**

- 返回 `douyin.com/note/<id>` 图文笔记，日期集中在 2026-10-11 至 10-18。
- `content` 字段带笔记正文，例："港城渝味火锅，超值团购，50元代金券（叠加秒杀后 19 元，团购价 25 元）"；"芙蓉王酒家·鲜炒湘味……剁椒蒸鱼头、邵阳血鸭"。
- 多为团购推广，口碑偏正面；没有原价、销量、poi_id 的结构化字段。
- douyin.com 的 robots.txt 对 Baiduspider 禁了 /note/ /shipin/ 等路径，但千帆仍返回 /note/ 结果和正文，实测为准。
- 限定 xiaohongshu.com 返回 0 条。
- 没充值也能调（应是免费额度），10-19 共用 7 次。

**笔记页本身拿不到：** `www.douyin.com/note/<id>` 返回 jsvmp 反爬挑战；`iesdouyin.com/share/note/<id>/` 和 `m.douyin.com/share/note/<id>` 是 SSR 空壳，正文由前端带签名接口拉取。按边界不碰。

**shipin / zhuanti 页：** 普通 GET 仍可用；`poiInfo` 字段存在但值为空，`anchorInfo` 为空。`/discover/poi`、`/jingxuan/poi`、`/video`、`/search`、`share/poi` 都是挑战页或空壳。

规律：同量级项目普遍用"用户自己的登录态 + 真实浏览器 + 低频"，单用户、单账号、本机运行。

缺口：没找到抓抖音门店或团购的开源项目（仓库搜索和代码搜索都没有），抖音相关的都是视频、评论、创作者数据。网页版门店页在登录态下是否显示团购列表，没有现成项目能回答，要实测。

## 5. 对设计的影响

- 团购表：结构化字段（原价、销量、poi_id）只能合成并标注；套餐名和团购价可以从千帆笔记正文、shipin 转写里用 LLM 抽取，对齐到高德门店。
- 发现：千帆 site=www.douyin.com 作为抖音笔记的发现入口；shipin 页发现改试 Bing、搜狗、360 类索引（百度被 robots 禁）。
- 付费路线：先注册灰豚或蝉妈妈免费账号（不付费），看深圳是否有数据、导出需要哪一档、导出列里有没有 poi_id；确认后再买一个月，手工导出海岸城一带的团购商品，按店名和坐标对齐高德门店。
- 需要用户和老师定：花钱买一个月服务商会员拿真实团购数据，还是接受"千帆笔记和 shipin 转写抽取，结构化字段合成并标注"，或由老师提供企业主体应用 / 商家授权。
