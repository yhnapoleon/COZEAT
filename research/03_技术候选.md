# 2025–2026.10 可引入技术核查（子代理报告原文，2026-10-17）

说明：数据均为论文或官方自报，未复现。"落地"指扣子低代码工作流 + 代码节点内能否实现。扣子平台能力依据 docs.coze.cn 官方文档。

## A 记忆与用户画像
- **Mem0**（arXiv 2504.19413，2025-04，github.com/mem0ai/mem0）：LLM 抽取事实 → ADD/UPDATE/DELETE 合并进向量库。自报 LoCoMo 上 p50 响应 0.708s、p95 1.44s（全上下文 9.87s）；注意 2606.16707 同骨干复现仅 29.3%，与官方数字差距大。用例：长期偏好（口味/预算/常去区域）增量合并而非每轮覆盖。落地：可——扣子"记忆库"（2025-10-15 升级，按 UID+渠道隔离，可跨智能体/工作流共享）已内置画像抽取；要自控 schema 则用数据库节点 + 代码节点复刻 ADD/UPDATE 判定。
- **LightMem**（2510.18866，2025-10，github.com/zjunlp/LightMem）：感觉记忆压缩 → 话题短期记忆 → "睡眠期"离线更新长期记忆。自报 LongMemEval 准确率最高 +7.7%，token 最多降 38×。用例：短期会话态（人数/时间/地点）在线、长期偏好离线定时归并的分层模板。落地：可——会话态放变量节点，长期归并用定时触发的工作流。
- **Memory-R1**（2508.19828，2025-08，v5 2026-01）：RL 训练记忆管理器在 ADD/UPDATE/DELETE/NOOP 四选一，仅 152 条 QA 训练；自报在 LoCoMo/MSC/LongMemEval 上优于 Mem0 等基线。用例：判定"今天想吃辣"是更新长期口味还是只记本次。落地：难——需微调 3B–14B 模型；扣子只能用 Prompt 模拟四选一。
- **MATE**（2610.06050，2026-10-05，单作者）：双记忆（长期保守更新 / 短期快速适应），按"历史重复支持度"和"近期一致性"两个时间信号给每次交互打分决定写入哪层；自报 NDCG@10 +7.0–13.2%（MovieLens/KuaiRec）。最贴近"推荐场景画像动态更新"的论文。落地：难（需训练）；两条打分规则可写成代码节点启发式。
- 对比/评测：MemAgent（字节 Seed，2507.02259，ICLR 2026）是长文本 RL 读取记忆，不是用户画像，不建议引用；A-MEM（2502.12110）、Zep/Graphiti（2501.13956，自报 LongMemEval +18.5%）、MemOS（2507.03724，自报 LoCoMo 全类第一）作对照。评测选 LongMemEval（2410.10813，ICLR 2025，含"知识更新"与"弃答"）而非 LoCoMo。2026 综述：2603.07670。工业落地：ChatGPT 2025-04-10 可引用全部历史；Claude 2025-09-11 Team/Enterprise、10-23 Pro/Max 上线记忆；豆包 2025 年底灰度（第三方报道，有用户反映长期记忆未写入）。未找到字节公开的画像记忆论文。

## B 对话式推荐与生成式推荐
- **Google 澄清提问**（2510.12015，2025-10，Boutilier 组）：仿扩散模型——从完整画像逐步"去掉答案"，再训练模型反向通过提问"去噪"。无自报数字。用例：参数缺失时先问区分度最大的属性。落地：难（需训练）；"漏斗式提问"原则可写进 Prompt。
- **COPE/InPE**（2607.06765，SIGIR 2026）：对话早期问属性、后期问具体项更有效，MoE 选策略。用例：多轮槽位调整时"何时问、何时推"。落地：可——按轮次/已填槽位数切换提问策略。
- **OneRec**（快手，2506.13695，2025-06；V2 2508.20900）：端到端生成式推荐替代级联；自报本地生活场景 GMV +21.01%。只能借鉴思想，不可落地。
- **HiAgentRec**（清华+美团，2604.14051，2026-04）：先预测"生活需求"→类目→门店，课程学习 + RLVR；自报 HR@1 +25.73%、线上 CTCVR +13.12%。用例：意图识别→类目→门店三段式可直接映射为三个 LLM 节点。落地：结构可，训练不可。
- 评测：**RecUserSim**（2507.22897，WWW 2025 Industry）带画像/记忆/有界理性动作模块的用户模拟器，可用另一工作流复刻。Agent4Rec（2310.10108）、iEvaLM（2305.13112）是 2023 基线，2403.16416 指出 iEvaLM 有目标项泄漏，评测时要用只给属性不给店名的模拟器。未找到字节/抖音生活服务公开推荐论文；快手 LGSID（2511.14221）为地理感知语义 ID。

## C RAG 与知识库
- **Contextual Retrieval**（Anthropic，2024-09）：切片前让 LLM 补上下文；自报 top-20 失败率 5.7%→2.9%（+上下文 BM25）→1.9%（+rerank）。用例：评价切片前补"店名/商圈/品类"。落地：可——上传前代码节点批处理。
- **Reconstructing Context**（2504.19754，ECIR 2025 workshop）：contextual retrieval 更准但贵，late chunking 便宜但随 embedding 波动；配合 rank fusion + rerank 最优。
- **Chunking 系统评测**（2603.06976，2026-03）：36 种策略 × 5 embedding，段落组切分最优（nDCG@5≈0.459），固定长度最差（<0.244）。落地：可（扣子自定义分段）。
- **结构化走 SQL**：Text2VectorSQL（2506.23071）论证纯 Text2SQL 在语义查询上执行准确率降 >32%，纯向量缺结构过滤；结论：门店表（价格/距离/营业时间）走 SQL，评价文本走向量。落地：可——扣子表格知识库默认开 NL2SQL 并与 RAG 切片合并，混合检索 + 重排为官方选项。
- 评测：RAGAS 足够；ARES（2311.09476）需几百条人工标注。2025–26 无显著新框架。

## D Prompt 自动优化
- **GEPA**（2507.19457，2025-07，ICLR 2026 oral，DSPy 内置）：对轨迹做自然语言反思 + Pareto 前沿进化；自报较 MIPROv2 +10% 以上，较 GRPO 平均 +6%，rollout 少 35×。用例：100–300 条标注对话离线优化意图/参数提取节点 Prompt，结果贴回扣子。落地：可（离线跑 DSPy）。
- **ACE**（2510.04618，2025-10，ICLR 2026）：上下文当可增量更新的 playbook，避免"简洁偏差/上下文塌缩"；自报 agent 任务 +10.6%，可无标注用执行反馈。用例：从失败对话积累规则。落地：可——playbook 存知识库，代码节点追加。
- 2026 年未见公认超越 GEPA 的方法；2603.25169 显示 GEPA 优化结果与专家手写多数无显著差异，收益取决于标注集质量。

## E 路线规划
- **形式化验证规划**（2404.11891，NAACL 2025）：LLM 抽约束→SMT 求解，自报 TravelPlanner 成功率 93.9%（GPT-4 直出 0.6%），不可满足时返回 unsat core 给修改建议。用例：3–5 家门店 + 顺路约束用代码节点穷举/回溯，不让 LLM 排序。落地：可。
- **ChinaTravel**（2412.13682，ICLR 2026）：中文 DSL 校验，神经符号 37.0% vs 纯神经约 1/10。借鉴：预算/时间窗/距离写成可校验规则。落地：可。

## F 工具调用可靠性
- **Agent Skills**（Anthropic 2025-10-16，2025-12-18 开放标准 agentskills.io）：SKILL.md 渐进加载。扣子无原生支持。落地：难（仅借鉴组织方式）。
- **MCP**：扣子 2025-09 起付费插件可封装为 MCP；2025-10/11 支持基于 MCP 服务建插件并在工作流调用；工作流可发布为 MCP；高德地图在官方 MCP 列表。落地：可。
- **ToolBench-X**（2606.25819，2026-06）：五类工具故障（规格漂移/调用错/执行失败/输出漂移/跨源冲突）各留一条恢复路径。用例：地图/搜索插件超时或空返回的重试/降级分支。落地：可——扣子 LLM 节点有超时（默认 180s）/重试 1 次 + 备选模型/异常分支并固定 JSON 输出；插件节点默认 3 分钟超时。
- 评测：BFCL v4（2025-07，agentic 占 40%）、τ²-bench（2506.07982）；2607.02577 审计发现评测器与人工 18.5% 不一致，Epoch 抽样 48% 任务有缺陷，别迷信榜单。
