# 现成方案与同类产品功能（子代理报告原文，2026-10-17，star/许可证/日期来自 GitHub API 实时读取）

## 结论先行
- 没有一个开源项目完整覆盖"意图→参数→SQL+向量→重排→卡片+长短期画像+高德"这条链；最接近的是 FloatTrip（LangGraph+高德 POI+长期偏好，国内作者，无许可证）和 ChinaTravel / Qwen DeepPlanning（中文 POI 沙盒+约束评测）。餐厅专属且 star≥50 的只有 What-to-eat-today（菜谱，非餐厅）。
- 扣子/Dify/FastGPT 公开模板里没有可直接导出的"探店/本地生活"工作流；只有旅游 Demo 和高德 MCP 示例。
- 餐饮对话评测集：中文只有 DuRecDial 2.0 含"美食/餐厅"域；英文 Yelp 系的 ConvRecStudio 未见代码发布；AgentSocietyChallenge（Yelp）可做画像/推荐离线评测。

### A2 低代码模板平台
- 扣子模板中心是 SPA 未核实；公开社区案例："云旅定制师"旅游 bot（https://www.feishu.cn/content/7340210087825604611 ，人设 prompt 可抄）、上海迪士尼路线助手（https://www.feishu.cn/content/7343535675272626179 ）。zprial/cozeworkflows（381 star，233 个可导入 JSON，无许可证）只有"菜品→制作方法卡片""拍照→营养分析卡片"两条美食相关，无餐厅/探店/本地生活。Coze Studio issues/discussions 无相关示例。
- Dify：svcvit/Awesome-Dify-Workflow（10.8k star，MIT）有 `旅行Demo.yml`（Agent 节点+会话变量存历史）和 `MCP-amap.yml`（高德 MCP 工具调用），无美食模板。
- FastGPT、百度 AppBuilder、腾讯元器：未得到旅游/美食官方模板页面。
