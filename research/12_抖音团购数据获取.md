# 抖音团购与门店数据怎么拿（2026-10-19）

问题：老师要看的是抖音自己的本地生活数据，即 App 里团购频道和门店页上的门店评分、人均、评价、团购套餐（名称、现价、原价、已售、使用规则）和心动榜。个人开发者怎么拿到。

边界：项目不商用；不破解签名、不绕过登录和验证码。

## 1. 官方渠道：个人都用不了

| 渠道 | 能拿到 | 门槛 |
|---|---|---|
| 生活服务 OpenAPI 门店、商品查询 | 自家门店与商品 | 商家应用或服务商，加商家授权 |
| 评分查询 `/goodlife/v1/akte/comment/score/query/`、评价查询 `/goodlife/v1/akte/comment/query/` | 评分、评价 | 同上，只查已授权商户 |
| 小程序生活服务 CPS 计划接口 | 自己的佣金计划、带货 GMV、带货达人 | 代运营服务商或自营商家的小程序 |
| 达人"选品广场"（App 创作者服务中心，PC 端 eos.douyin.com） | 按城市、商圈、类目搜团购商品，按销量、价格、佣金、距离排序，详情能看评价 | 只有界面没有 API；PC 端要 1000 粉且入驻团购达人中心 |
| POI 热度榜 `/data/external/poi/billboard/` | 门店名、排名、分 | 特殊权限，文档写"暂不支持线上申请" |
| 心动榜、抖音分 | | 只在 App 内，无接口 |

来源：developer.open-douyin.com 生活服务文档、小程序 CPS 指南。

## 2. 公开网页：门店页和团购页走不通

- 门店 H5 `aweme.snssdk.com/falcon/poi_mwa/poi_detail?poi_id=<id>` 和团购 H5 `.../trade_detail?activity_id=<id>` 普通请求返回 200，但页面是前端渲染的空壳，任何 id（包括 `poi_id=1`）返回的都是同一份页面。数据走 `/v1/poi/detail_web` 接口，页面配置写明该接口有 bdms 签名和验证码保护，不做。
- www.douyin.com 下没有团购频道和门店页，`/lifeservice` 返回 404。
- 抖音的独立团购 App"抖省省"（北京抖音科技，2026-02 上线）没有网页版。

## 3. 能拿到的两条路

### 3.1 抖音团购商品：第三方 CPS 平台（聚推客）

- 商品搜索接口 `search_product_list`（jutuike.com/doc/131，第三方，子代理读到，本机连不上该站，未亲自核实）：
  - 入参：city_code、longitude/latitude（WGS84）、distance_max、category_id、key_word、sort_by（距离、销量、价格、佣金）。
  - 返回：name（套餐名）、price、origin_price、blurred_sold_count（模糊销量）、nearest_poi（name、poi_id）、poi_count、类目、commission_rate/amount、dy_h5_url。
  - 另有城市、商品详情（doc/132）、转链、订单接口。详情接口是否含套餐内容、使用规则未核实。
- 首页称个人和企业都能参与，API 免费。
- 范围：只有商家设了佣金、开放推广的商品，不是全量。餐饮团购里开推广的比例未知，拿到 key 后按深圳几个商圈实测覆盖率。
- 备选：好单库 `dy_life_list`（需 apikey，字段未查到）。美团联盟 `query_coupon` 能查到店团购，带"点评高分 4.6"这类标签，个人能否注册未查到。

### 3.2 抖音探店视频的口播转写：`douyin.com/shipin/<id>` 页

- 这是给搜索引擎准备的话题聚合页，普通 GET 返回 200，服务端渲染的数据里有一组视频，每条带：awemeId、text（文案）、nickname、diggCount、videoUrl、duration、updateTS、**asrText（完整口播转写）**。
- 实测两个深圳页面：南山页 20 条视频、19 条有转写、平均约 320 字、更新于 2025-12 到 2026-08；深圳湾万象城页 21 条、7 条有转写、最新 2026-09。
- 转写内容示例："只要九十八就可以吃这个碳烤小青龙四人餐……另外还有一份碳烤大生蚝以及南美大虾，一份碳烤扇贝，还有烤牛肉串……就连餐具纸巾都给你包含了"。有价格、套餐内容、位置、场景。
- 局限：
  - 门店和团购锚点字段为空，店名要从文案和转写里抽。
  - 多是带团购链接的达人推广视频（"刷到的朋友们左下角买了过来试试"），适合提取套餐内容、价格、热度，当中立评价要打折扣。
  - 文案里的 #心动榜餐厅 话题可以作为"参与心动榜"的弱信号。
- 发现：搜索引擎收录 `/shipin/<id>`，用搜索 API 加 `douyin.com/shipin` 和"商圈 + 品类"查询。

## 4. 每项数据的最终来源

| 数据 | 来源 | 说明 |
|---|---|---|
| 门店基础、坐标、营业时间 | 高德 POI 2.0 | |
| 评分、人均 | 高德；点评探店笔记的 shopPower、avgPrice | 抖音分拿不到 |
| 团购套餐名、现价、原价、销量 | 聚推客商品搜索 | 只覆盖开放推广的商品；没覆盖到的店再合成并标注 |
| 套餐内容 | 聚推客详情（待核实）；抖音探店视频转写 | |
| 抖音侧评价与热度 | 抖音 `/shipin/` 页的转写、点赞、更新时间 | 推广口吻多 |
| 近期 UGC 评价、推荐菜、场景 | 小红书笔记、点评探店笔记 | 见 research/11 |
| 心动榜 | 媒体稿名单 + 视频话题 #心动榜餐厅 | 无接口 |
| 门店跨平台对齐 | 高德 amap_id 为主键；聚推客 nearest_poi 给抖音 poi_id | |

## 5. 需要用户做的

1. 注册聚推客（个人），拿 apikey。拿到后先测深圳南山、福田各 2 个商圈的餐饮团购覆盖率。
2. 豆包搜索 Custom 的 key（见 research/11），同时用来发现小红书笔记、点评探店笔记和抖音 `/shipin/` 页。
